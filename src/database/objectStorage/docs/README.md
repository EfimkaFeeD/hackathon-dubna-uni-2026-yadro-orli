Объектное хранилище

Особенности:

- Связь через HTTP
- Прослушивание http://localhost:8081

Запросы:

- Сохранение чанка

Структура запроса: PUT /v1/objects/put/{file_id}/{key}

Коды ошибок:

201 Created	(успешно)

400 Bad Request	(пустое тело запроса)

500 Internal Server Error

* Загрузка чанка

Структура запроса: GET /v1/objects/get/{file_id}/{key}

Коды ошибок:

200 OK	(успешно)

404 Not Found 

* Удаление одного чанка

Структура запроса: DELETE /v1/objects/delete/{file_id}/{key}

Коды ошибок:

204 No Content (успешно)

404 Not Found 

* Удаление всех чанков файла

Структура запроса: DELETE /v1/objects/all/{file_id}

Кодовые ошибки:

204 No Content (успешно)

404 Not Found 

* Получение списка всех чанков файла

Структура запроса: GET /v1/objects/list/{file_id}

Пример тела ответа:

      {
         "file_id": 123,
         "chunks_count": 3,
         "total_size": 1024,
         "chunks": ["chunk_001", "chunk_002", "metadata"]
      }

* Получение списка всех файлов

Структура запроса: GET /v1/objects/all

Пример тела ответа:

    {
        "total_files": 2,
        "file_ids": [123, 456]
    }

* Проверка связи с объектным хранилищем

Структура запроса: GET /health

Кодовые ошибки:

200 OK 

Принцип работы:

* Сохранение чанка в словаре (ключ - file_id + key, значение - массив байтов)
* Сохранение чанка на диске по директории
* При достижении определенного размера в словаре чистятся данные
* Размер для кэша задается
